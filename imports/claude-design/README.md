## Output rules (from CLAUDE.md in project 855e7c43)

- For each brief in an "OVXS content batch", build one tabbed page with a tab for each item under "Make".
- LinkedIn post: LinkedIn-style preview + 4:5 graphic with photo.
- IG carousel: 8 slides, 4:5, photos on cover and problem slides.
- Also Newsletter and Article tabs when listed. LinkedIn video: script + shot list tab.
- Styling: IvyPresto headings with `<em>` wavy-underline payoff, Elza Condensed buttons, Inter body, teal `#1b6a63`.
- Make only the listed items. Write the copy to `content/brief-N-*.md`.
- Voice: plain, honest, we → you, sentence case.
- CTA: "$99 video audit", credited back if we work together.
